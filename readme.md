# Project Statement 17: Startup Website Deployment

## 1. Project Objective
The objective of this project is to enable students to design a startup website using HTML and CSS and deploy it using Git and AWS.

## 2. Project Information
- *Project Title:* Startup Website Deployment
- *Difficulty Level:* Intermediate
- *Primary Skills:* HTML, CSS Flexbox, Git, AWS
- *Dataset Source:* Self-Created Content

## 3. Problem Description
Create a modern startup website including Home, Features, Pricing, and Contact sections and deploy it using AWS.

## 4. Required Steps
1. Create HTML structure.
2. Add startup sections (Home, Features, Pricing, Contact).
3. Use Flexbox for layout.
4. Style UI using CSS.
5. Add images and icons.
6. Apply responsive design.
7. Initialize Git repository.
8. Push code to GitHub.
9. Deploy on AWS S3.
10. Test and validate.
